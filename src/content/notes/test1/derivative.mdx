导数回答一个问题：**在某一瞬间，函数变化得多快？**

## 导数的定义

函数 f 在 x₀ 处的导数定义为极限：

> f'(x₀) = lim(h→0) [f(x₀ + h) - f(x₀)] / h

当这个极限存在时，称 f 在 x₀ 处可导。几何上，f'(x₀) 就是曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率。

## 基本求导法则

### 四则运算

设 u = u(x)，v = v(x) 都可导：

1. **和差**：(u ± v)' = u' ± v'
2. **积**：(uv)' = u'v + uv'
3. **商**：(u/v)' = (u'v - uv') / v²（v ≠ 0）

### 链式法则（复合函数）

若 y = f(g(x))，则：

> dy/dx = f'(g(x)) · g'(x)

链式法则是求导最常用的工具之一，处理嵌套函数时离不开它。

## 常见函数的导数

| 函数 f(x) | 导数 f'(x) |
| --------- | ---------- |
| c（常数） | 0          |
| xⁿ        | n·xⁿ⁻¹     |
| eˣ        | eˣ         |
| ln(x)     | 1/x        |
| sin(x)    | cos(x)     |
| cos(x)    | -sin(x)    |
| tan(x)    | sec²(x)    |

## 高阶导数

对导数再求导得到二阶导数 f''(x)，物理上常表示加速度。一般地，n 阶导数 f⁽ⁿ⁾(x) 表示对 f 连续求导 n 次。

例如对位置函数 s(t) 求导得速度 v(t) = s'(t)，再求导得加速度 a(t) = v'(t) = s''(t)。

## 微分

当 f 在 x₀ 可导时，函数值的增量可以写成：

> Δy = f'(x₀)·Δx + o(Δx)

其中 f'(x₀)·Δx 称为函数在 x₀ 处的**微分**，记作 dy。当 Δx 很小时，可以用 dy 近似代替 Δy，这是许多近似计算的基础。

## 小结

导数是局部变化率的精确度量，微分则是用它做线性近似。下一篇将从"求变化率"转向"求累积"，进入积分的世界。
