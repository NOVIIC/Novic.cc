二重积分把一维区间上的定积分推广到二维平面区域上，本质仍是"分割、求和、取极限"。

## 定义

设 f(x, y) 是有界闭区域 D 上的有界函数。将 D 任意分割成 n 个小区域 Δσᵢ，在每个小区域上任取一点 (ξᵢ, ηᵢ)，作和式：

> Σᵢ f(ξᵢ, ηᵢ) · Δσᵢ

当各小区域直径的最大值 λ → 0 时，若该和式极限存在且与分割、取点方式无关，则称此极限为 f 在 D 上的二重积分：

> ∬_D f(x, y) dσ

几何意义：当 f(x, y) ≥ 0 时，二重积分表示以 D 为底、z = f(x, y) 为顶的曲顶柱体的体积。

## 直角坐标下的计算

关键是把二重积分化为**累次积分**——两次定积分。

### X-型区域

若 D 可表示为 a ≤ x ≤ b，φ₁(x) ≤ y ≤ φ₂(x)，则：

> ∬_D f(x, y) dA = ∫ₐᵇ dx ∫_\{φ₁(x)\}^\{φ₂(x)\} f(x, y) dy

先对 y 积分（把 x 看作常数），再对 x 积分。

### Y-型区域

若 D 可表示为 c ≤ y ≤ d，ψ₁(y) ≤ x ≤ ψ₂(y)，则：

> ∬_D f(x, y) dA = ∫ᶜᵈ dy ∫_\{ψ₁(y)\}^\{ψ₂(y)\} f(x, y) dx

## 一个例子

计算 ∬_D xy dA，其中 D 是由直线 y = x、y = 1、x = 0 围成的三角形。

先把区域写成 X-型：0 ≤ x ≤ 1，x ≤ y ≤ 1。于是：

> ∬_D xy dA = ∫₀¹ dx ∫_x¹ xy dy

内层积分（x 视为常数）：

> ∫_x¹ xy dy = x · [y²/2]_x¹ = x · (1/2 - x²/2) = (x - x³)/2

外层积分：

> ∫₀¹ (x - x³)/2 dx = 1/2 · [x²/2 - x⁴/4]₀¹ = 1/2 · (1/2 - 1/4) = 1/8

## 极坐标

当积分区域与圆有关时，用极坐标更方便。令 x = r cosθ，y = r sinθ，则 dA = r dr dθ：

> ∬_D f(x, y) dA = ∬_\{D'\} f(r cosθ, r sinθ) · r dr dθ

注意那个多出来的 r——极坐标下面积元素是 r dr dθ，不是 dr dθ。

## 小结

二重积分的核心技巧是**选择合适的积分顺序与坐标系**。下一篇将进入三维，讨论三重积分。
