三重积分把二重积分再推广一维，用于在空间区域 Ω 上对函数 f(x, y, z) 求积分。

## 定义

> ∭_Ω f(x, y, z) dV

当 f 表示密度时，三重积分给出物体的总质量。

## 直角坐标下的累次积分

若 Ω 可表示为 a ≤ x ≤ b，y₁(x) ≤ y ≤ y₂(x)，z₁(x,y) ≤ z ≤ z₂(x,y)，则：

> ∭*Ω f dV = ∫ₐᵇ dx ∫*\{y₁(x)\}^\{y₂(x)\} dy ∫\_\{z₁(x,y)\}^\{z₂(x,y)\} f(x, y, z) dz

由内到外依次积分 z、y、x。确定上下限的关键是**画清区域、定好投影**。

## 柱坐标

当区域关于某轴（常取 z 轴）有旋转对称性时，用柱坐标更方便：

- x = r cosθ
- y = r sinθ
- z = z

体积元素 dV = r dr dθ dz，于是：

> ∭*Ω f dV = ∭*\{Ω'\} f(r cosθ, r sinθ, z) · r dr dθ dz

柱坐标本质上是"极坐标 + z"，多出来的 r 同样来自极坐标的面积元素。

## 球坐标

当区域与球面、圆锥有关时，用球坐标最合适：

- x = r sinφ cosθ
- y = r sinφ sinθ
- z = r cosφ

其中 r 是到原点距离，φ 是与 z 轴正向的夹角，θ 是在 xy 平面上的方位角。体积元素：

> dV = r² sinφ dr dφ dθ

注意 r² sinφ 这个因子——它比柱坐标又复杂了一层，初学时最容易遗漏 sinφ。

## 一个例子：球的体积

用球坐标求半径为 R 的球体体积。Ω 为 0 ≤ r ≤ R，0 ≤ φ ≤ π，0 ≤ θ ≤ 2π：

> V = ∫₀²π dθ ∫₀ᵖ sinφ dφ ∫₀ᴿ r² dr
> = 2π · [-cosφ]₀ᵖ · [r³/3]₀ᴿ
> = 2π · 2 · R³/3
> = 4πR³/3

这正是球体积公式。

## 坐标系的选择

| 区域特征               | 推荐坐标系 |
| ---------------------- | ---------- |
| 长方体、一般区域       | 直角坐标   |
| 绕某轴旋转对称         | 柱坐标     |
| 球面、球锥、同心球区域 | 球坐标     |

## 小结

三重积分的难点不在积分本身，而在**画图定限**与**选对坐标系**。多画图、多练习投影是关键。
