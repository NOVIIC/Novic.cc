极限是微积分的地基。整个微积分的大厦——导数、积分、级数——都建立在极限之上。

## 数列极限

设 \{aₙ\} 是一个数列，如果存在常数 L，使得当 n → ∞ 时 aₙ 无限趋近于 L，则称 L 为数列的极限：

> lim(n→∞) aₙ = L

### 一个经典例子

考察数列 aₙ = (1 + 1/n)ⁿ。可以证明当 n → ∞ 时它收敛到自然常数 e ≈ 2.71828...

直观地看，当 n 越来越大，(1 + 1/n)ⁿ 的值会稳定地逼近 e，既不会超过太多，也不会偏离太远。

## 函数极限

函数极限描述函数在自变量趋近某点时的行为。

### 极限的定义（ε-δ 语言）

设函数 f(x) 在 x₀ 的某去心邻域内有定义。如果存在常数 L，对于任意 ε > 0，都存在 δ > 0，使得当 0 < |x - x₀| < δ 时，有 |f(x) - L| < ε，则称 L 是 f(x) 在 x → x₀ 时的极限。

这个定义看起来拗口，但核心思想很朴素：**无论你要求 f(x) 多么接近 L（给定 ε），我总能找到一个范围 δ，让 x 足够靠近 x₀ 时就满足要求**。

## 极限的运算性质

若 lim f(x) 和 lim g(x) 都存在，则：

1. **和差**：lim [f(x) ± g(x)] = lim f(x) ± lim g(x)
2. **积**：lim [f(x)·g(x)] = lim f(x) · lim g(x)
3. **商**：lim [f(x)/g(x)] = lim f(x) / lim g(x)（分母极限不为 0）

## 连续性

函数 f 在 x₀ 处连续，需要同时满足三个条件：

- f(x₀) 有定义
- lim(x→x₀) f(x) 存在
- lim(x→x₀) f(x) = f(x₀)

连续函数有良好的性质：闭区间上的连续函数一定有最大值与最小值（最值定理），且能取到中间的每一个值（介值定理）。

## 小结

极限给了我们一种精确描述"无限趋近"的语言。下一篇将在此基础上讨论导数——瞬时变化率。
